FAQ

Questions, answered.

Do I need to own Minecraft?

Yes — Vape Client is a launcher, not a replacement for the game. You need a Microsoft account with Minecraft Java Edition.

Does it modify in-game behavior or give unfair advantages?

No. Vape Client is a launcher only. It tunes launch settings, JVM arguments, and client-side files — it does not touch server-side gameplay, and every server setting stays exactly as the server intends.

Is it safe for my account?

Yes. Sign-in uses Microsoft's official OAuth flow. Your credentials are never stored or transmitted to any external server.

Will it work with my mods?

Separate profiles keep vanilla and modded setups isolated, so existing mod folders and configs are never touched.

Is there a Mac or Linux version?

Not yet — we're focused on Windows first. Follow us for updates.
